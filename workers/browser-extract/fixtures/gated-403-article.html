How closures capture variables

A closure is a function plus the lexical environment recorded when that function was created. The inner function can still read outer bindings after the outer function has returned.

Steps

  1. Declare the outer function and its locals.
  2. Return an inner function that reads those locals.
  3. Call the inner function later and observe the captured values.
function makeAdder(x) {
  return function add(y) {
    return x + y;
  };
}

const addFive = makeAdder(5);
console.log(addFive(2));
