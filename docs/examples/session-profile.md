# Example: Session profile

```json
{
  "name": "occam_transcode",
  "arguments": {
    "url": "https://example.com/account",
    "session_profile": "example-com",
    "backend_policy": "browser"
  }
}
```

Create/list profiles with the operator CLI (`occam session`) from an install where `OCCAM_HOME/scripts` is on `PATH`. Profiles are local files — do not commit them.
