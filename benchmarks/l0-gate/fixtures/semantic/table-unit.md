# Timeouts

Default request timeouts for the proxy.

| Directive | Value | Unit |
|-----------|------:|------|
| proxy_connect_timeout | 30 | seconds |
| proxy_read_timeout | 60 | seconds |
| proxy_send_timeout | 60 | seconds |

Keep units with the numbers. Do not treat 30 as milliseconds.

`proxy_read_timeout` is the socket read deadline.
