# ff-occam

Primary npm package for **FF Occam** — the verifiable web materialization MCP host.

```bash
npx ff-occam
npx occam --help
```

This package is a thin CLI wrapper around [`@ff-occam/mcp`](../occam-mcp) (same version pin). Use `OCCAM_HOME` to point at a local checkout and skip release download.

See [docs/getting-started.md](../../docs/getting-started.md).
